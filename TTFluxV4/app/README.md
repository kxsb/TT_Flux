# TTFlux V4 app

Interface locale à construire après le socle CLI.

Objectif UI minimal :

1. lister les vidéos brutes ;
2. afficher fps, résolution, durée ;
3. sélectionner une vidéo ;
4. lancer une analyse balle ;
5. ouvrir overlay, métriques et dossier de sortie.

Décision provisoire : commencer simple. Streamlit ou Tkinter acceptable, mais les traitements doivent rester dans `src/ttflux/`.
