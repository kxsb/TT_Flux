# TTFlux

TTFlux est le nouveau socle propre de PingCoach.

Objectif v0 :
- lire un CSV de tracking balle existant
- sélectionner automatiquement des segments propres
- générer des vidéos overlay de contrôle
- produire un JSON de scoring reproductible

Ce dépôt ne contient pas encore :
- TTNet
- SpinTrajectory
- calibration caméra
- modèle IA lourd

Ce code n'est pas utilisable en l'état.
